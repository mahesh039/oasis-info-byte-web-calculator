# 🧮 Modern Web Calculator

A **Modern Web Calculator** built using **HTML, CSS, and JavaScript**.  
This project performs basic arithmetic calculations with a clean, simple, and responsive user interface.

It is a beginner-friendly project that helps in understanding **JavaScript logic, DOM manipulation, and basic web development concepts**.

---

## 📖 Project Overview

The Modern Web Calculator is a simple web application designed to perform basic mathematical operations such as:

- Addition
- Subtraction
- Multiplication
- Division

This project demonstrates how **HTML structures the application, CSS styles the interface, and JavaScript handles the calculation logic**.

---

## ✨ Features

- Simple and user-friendly interface
- Performs basic arithmetic calculations
- Responsive design
- Fast and accurate results
- Lightweight and easy to run
- Beginner-friendly project

## 📂 Project Structure

```

│
├── index.html

│   └── video
│
└── README.md
```

### File Explanation

**index.html**  
Contains the structure of the calculator including buttons and display.

**style.css**  
Handles the design, layout, and responsiveness of the calculator interface.

**script.js**  
Contains JavaScript code for performing mathematical operations and handling button actions.

**assets/**  
Stores project images and demo videos.

## ▶️ How to Run the Project

Follow these steps to run the calculator on your computer.

1. Download or clone this repository

```
git clone https://github.com/your-username/modern-web-calculator.git
```

2. Open the project folder

3. Open the file **index.html** in any web browser

4. The calculator will start working
